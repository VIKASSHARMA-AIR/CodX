4-Step Physical Phone Testing Sequence

How to test and verify the offline-first recording guarantee between two phones.

01

Install & Open Recorder

Install CodX Recorder on Phone A. Grant microphone and notification permissions. Note the 6-digit code on screen (e.g. CDX-4829).

02

Login on Controller

Install CodX Controller on Phone B. Tap "Sign in with Google" or choose "Sign in with Demo Account". View your active profile badge.

03

Pair Devices & Set Schedule

Under the Pair tab, enter the 6-digit code from Phone A. Once paired, create a recording timetable starting 2 minutes in the future.

04

Offline-First Verification

Turn OFF Wi-Fi and mobile data on Phone A, and reboot Phone A. When the scheduled time arrives, Phone A wakes up and records completely offline!

1. Data Collected

We collect Google account identifiers (name, email, profile photo, Firebase UID), hardware telemetry (battery %, charging state, available storage), and encrypted audio files.

3. Data Security

All transfers utilize TLS 1.2/1.3 encryption. Audio files are validated with cryptographic SHA-256 checksums.
